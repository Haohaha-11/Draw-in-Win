# V形恢复图参数调整说明

## 一、阴影范围调整

### 【参数1】高点和低点的位置
```python
min_idx = 1  # 最低点位置：第2赛季（索引从0开始，所以1代表第2个数据点）
max_idx = 4  # 最高点位置：第5赛季（索引4代表第5个数据点）
```
- **作用**：定义V形恢复的起点（最低点）和终点（最高点）
- **如何修改**：
  - 如果想改为第3赛季到第4赛季，设置 `min_idx = 2, max_idx = 3`
  - 索引规则：第1赛季=0，第2赛季=1，第3赛季=2，以此类推

### 【参数2】阴影覆盖范围
```python
recovery_seasons = seasons[min_idx:max_idx+1]
recovery_values = ours_data[min_idx:max_idx+1]
```
- **作用**：自动根据min_idx和max_idx确定阴影范围
- **无需手动修改**：会自动跟随参数1的设置

### 【参数3】阴影透明度和颜色
```python
ax.fill_between(recovery_seasons, recovery_values, y_min,
                alpha=0.75,           # 阴影透明度
                color='#2d1d96',      # 阴影颜色
                ...)
```
- **alpha**：透明度，范围0-1
  - 0 = 完全透明（看不见）
  - 0.75 = 当前设置（75%不透明）
  - 1 = 完全不透明
- **color**：阴影颜色（十六进制颜色码）
  - 当前：`#2d1d96`（深蓝紫色，与Ours曲线一致）

## 二、高点和低点标记调整

### 【参数4】最低点标记
```python
ax.scatter([seasons[min_idx]], [min_value],
          s=350,                    # 散点大小
          color='#2d1d96',          # 散点颜色
          edgecolors='white',       # 边框颜色
          linewidths=3,             # 边框宽度
          marker='o',               # 标记形状
          ...)
```

### 【参数5】最高点标记
```python
ax.scatter([seasons[max_idx]], [max_value],
          s=350,                    # 散点大小
          color='#2d1d96',          # 散点颜色
          edgecolors='white',       # 边框颜色
          linewidths=3,             # 边框宽度
          marker='o',               # 标记形状
          ...)
```

**可调整参数：**
- **s**：散点大小
  - 当前：350
  - 建议范围：200-500
  - 数值越大，圆圈越大

- **color**：散点填充颜色
  - 当前：`#2d1d96`（与Ours曲线颜色一致）
  - 可改为其他颜色，如：`#ff0000`（红色）、`#00ff00`（绿色）

- **edgecolors**：边框颜色
  - 当前：`white`（白色）
  - 可改为：`black`、`#2d1d96`等

- **linewidths**：边框宽度
  - 当前：3
  - 建议范围：1-5
  - 数值越大，边框越粗

- **marker**：标记形状
  - 当前：`'o'`（圆形）
  - 其他选项：`'s'`（方形）、`'^'`（上三角）、`'v'`（下三角）、`'D'`（菱形）

## 三、数值标注调整

### 【参数6】最低点数值标注
```python
ax.text(seasons[min_idx], min_value + 0.15,  # 垂直偏移
        f'{min_value:.3f}',                    # 小数位数
        fontsize=10,                           # 字体大小
        color='#2d1d96',                       # 字体颜色
        ...)
```

### 【参数7】最高点数值标注
```python
ax.text(seasons[max_idx], max_value + 0.15,  # 垂直偏移
        f'{max_value:.3f}',                    # 小数位数
        fontsize=10,                           # 字体大小
        color='#2d1d96',                       # 字体颜色
        ...)
```

**可调整参数：**
- **垂直偏移**：`min_value + 0.15`
  - 当前：0.15（标注在点上方0.15单位）
  - 增大数值：标注离点更远
  - 减小数值：标注离点更近
  - 负数：标注在点下方

- **小数位数**：`f'{min_value:.3f}'`
  - `.3f` = 3位小数
  - `.2f` = 2位小数
  - `.4f` = 4位小数

- **fontsize**：字体大小
  - 当前：10
  - 建议范围：8-14

- **color**：字体颜色
  - 当前：`#2d1d96`（与曲线颜色一致）
